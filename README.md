# 3 MONTHS 片付けコーチ

3か月かけて、家の気になる場所を少しずつ
「散らかっても戻せる状態」にする片付けコーチです。

アプリが毎日2つの小さな片付け（A/B）を提案し、
ユーザーは選んで、5分やって、結果だけ答えます。
明日の内容はアプリが考えます。

## 主な機能

- はじめの設定は3ステップ（気になる場所を最大3つ／一番困っていること／3か月後の理想）。開始日は必要な場合だけ今日以前へ変更可能
- 毎日の A/B
  - A：今取り組んでいる場所を少し進める
  - B：モノ別5分片付け（45品目のメニューから。「別のモノにする」で変更可）
- 「今日はちょっと無理」で2〜3分の小さい版に切り替え（「通常版に戻す」で元に戻せる）
- 土日は通常進行と分離した1〜3分の週末ミニを表示（希望すれば通常版へ切り替え可能）
- 結果は「できた／少しできた／今日はできなかった」の3択と、必要なときだけ1問
- 結果に合わせて翌日の内容が変わる
  - できた → 次の段階へ
  - 少しできた → 同じ対象を半分くらいで
  - できなかった → 2〜3分のミニ版
  - 結果保存後に平日が4日以上あいた → 小さな再開タスク（土日、未選択、未保存は未達成扱いにしない）
- 約7日ごとの軽いふり返り、一区切りした場所の再確認（7日後、以降14日ごと）
- 3か月画面で期間・重点エリアの状態（整え中／一区切り／これから）を確認・編集
- 3か月の終わりに最終ふり返り → 「次の3か月を始める」または「いったん休む」
- カレンダーから過去の記録を確認し、結果と回答を修正

外部AIやサーバーは使用せず、指示はすべてブラウザ内のルールで決まります。

## 使用技術

- HTML
- CSS
- Vanilla JavaScript
- localStorage

フォントは Google Fonts から読み込みます（読み込めない場合は端末のフォントで表示されます）。

## ファイル構成

```text
index.html   画面の構造
style.css    デザイン
coach.js     A/Bの生成ロジック（エリアの段階・モノ別メニュー・分岐）
script.js    データ保存・画面描画・操作
```

## 起動方法

`index.html` をブラウザで開くだけで動きます。

## データ保存について

データはブラウザのlocalStorage（キー：`hundredDaysChallenge`、`schemaVersion: 3`）に保存されます。

ブラウザデータを削除した場合や、
別の端末・ブラウザではデータは引き継がれません。

以前のバージョン（100日チャレンジ・片付けコーチ）の記録は削除せずに残し、カレンダーで閲覧できます。

## GitHub Pages

GitHub Pagesで公開可能です。

1. リポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」にする
3. Branch を `main`、フォルダを `/ (root)` にして Save
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
